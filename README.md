# UCN Reader

서비스가 끝난 **유씨노벨(UCnovel)** 의 작품 파일 `.ucn`을 브라우저에서 다시 재생하는 웹 플레이어입니다.
설치나 서버 없이 페이지를 열고 파일을 끌어다 놓으면 됩니다. 파일은 업로드되지 않고 브라우저 안에서만 열립니다.

> 유씨노벨은 2019년 11월 15일 서비스를 종료했습니다. 이 프로젝트는 개인이 보관한 `.ucn` 파일을 다시 볼 수 있도록
> 파일 포맷과 공식 안드로이드 플레이어 동작을 역공학해 만든 비공식 도구이며, 유씨노벨과 관련이 없습니다.

## 기능

| 기능 | 설명 |
|---|---|
| 재생 | 장(page) 단위 재생. 배경 → 이미지(z 순서) → 텍스트 순으로 겹쳐 그리고, fade/vortex 등장·퇴장 효과, 자동 넘김 장(오프닝 등)을 원본 시간대로 재현 |
| 텍스트 | 한 글자씩 출력(원본 기본 속도 글자당 15ms), 줄바꿈·`#p`·`#w;`에서 클릭 대기 등 원본 플레이어 규칙 그대로 |
| 음악 표시 | 음원은 파일에 들어 있지 않아 재생하지 않음. 해당 장에서 진행 중인 곡 이름만 오른쪽 아래에 `▶ 제목.mp3`로 흐리게 표시 |
| 사진 전부 받기 | 파일 안 이미지 전체를 `파일명_사진.zip`으로 저장(장면에 쓰이지 않은 사진 포함, 원본 바이트 그대로) |
| 글 전부 저장 | 대사·서술을 장 순서대로 `파일명_글.txt`로 저장. `[19장]` 머리표, 곡이 바뀌는 지점에 `♪ 곡명`, 태그 제거, `$변수;`는 `[변수]` |
| Log 보기 | 파일 해석·재생의 모든 단계를 성공/정보/경고/오류로 기록. 복사·txt 저장 가능, 오류 개수 배지 표시 |
| 깨진 파일 | 일부 엔트리가 손상돼도 멈추지 않고 읽을 수 있는 데까지 열며, 어디서 왜 실패했는지 로그에 남김 |

## 사용법

1. 페이지를 엽니다(배포 주소 또는 로컬의 `player/index.html`).
2. **파일 선택**을 누르거나 `.ucn` 파일을 화면 아무 곳에 끌어다 놓습니다.
3. "클릭해서 시작"이 나오면 클릭합니다.
4. 왼쪽 아래 도구에서 **사진 전부 받기 · 글 전부 저장 · 다른 파일 열기 · Log 보기**를 쓸 수 있습니다.

## 조작

| 동작 | 마우스·터치 | 키보드 |
|---|---|---|
| 다음 (출력 중이면 즉시 완성 → 멈춘 곳이면 이어서 출력 → 다 나왔으면 다음 장) | 화면 클릭/터치 | `Space` `Enter` `→` `PageDown` |
| 이전 장 | (없음) | `←` `PageUp` |
| 로그 닫기 | `닫기` | `Esc` |
| 처음부터 | 끝 화면의 `처음부터` | – |

- 오프닝처럼 자동 넘김이 지정된 장도 클릭하면 바로 넘어갑니다.
- 이전 장으로 가면 그 장을 처음부터 다시 출력합니다.

## 지원 범위와 한계

검증은 실제 작품 파일 **1개**(210장, 이미지 83장, 2019년 8월 작성)로 했습니다. 다른 작품은 아래 항목 때문에 다르게 보일 수 있으며, 그런 경우 **Log 보기**에 경고로 표시됩니다.

**지원**
- 컨테이너 해제(UC/PK 헤더, hex 파일명, zlib 데이터), `script.xml` 해석
- 레이어: `back`(배경), `image`(겹침 이미지), `scenario`(텍스트), `bgm`(곡 이름 표시만)
- 효과: `fade`, `vortex`(회전+확대로 근사), `none`
- 장 넘김: 클릭(`delay mode="scen"`), 자동(`delay mode=""`, ms)
- 텍스트 태그: 줄바꿈/`#p`(클릭 대기), `#w;`(줄 중간 클릭 대기), `#c;`, `#d.N;`, `$변수;`(값 없음 → 빈칸)

**미지원 / 차이**
- **음원 재생 불가**: `.ucn`에는 음원이 없고 원래 서버(`kr.my.ucnovel.com`)는 종료됨. Wayback Machine에도 남아 있지 않음(확인한 범위).
- **작품 스크립트(UCscript) 미실행**: 선택지, 이름 입력, 조건 분기, `gotoPage` 등 스크립트 기반 기능은 동작하지 않음. `$이름;` 같은 변수는 빈칸.
- **컴포넌트 미지원**: 버튼, 입력창, 텍스트, 타이머, 그래프, 스프라이트, 동영상, 애니메이션.
- **장면(scene) 1개만 재생**: 여러 장면이 있으면 첫 장면만.
- **텍스트 스타일 일부만 반영**: 위치·크기·색·정렬·여백·줄간격. 외곽선은 검정 1px 고정, 배경·테두리·그림자·노드별 글꼴은 무시. 글꼴은 나눔고딕.
- **독자 설정 고정**: 원본의 타이핑 속도·넘김 방식(클릭/자동) 설정 대신 원본 기본값(속도 70, 클릭 넘김) 사용. 노드별 `speed`/`event` 값은 아직 반영하지 않음.
- **효과음**(`@effect`) 미지원, 알 수 없는 등장 효과는 fade로 처리.
- 휴대폰 세로 화면에서는 800×480 비율 그대로라 작게 보이며, 터치로 이전 장 이동은 없음.
- 저장/이어보기, 장 번호 표시·이동 없음.

## 개인정보·외부 요청

- `.ucn` 파일은 **브라우저 메모리에서만** 처리되며 어떤 서버로도 전송되지 않습니다. 사진 zip·글 txt·로그도 브라우저에서 만들어 바로 내려받습니다.
- 외부 요청은 **Google Fonts(나눔고딕 글꼴)** 하나뿐입니다. 글꼴을 못 불러오면 기기 기본 글꼴로 표시됩니다.
- 분석 도구·쿠키·로컬 저장소를 쓰지 않습니다.
- 로그에는 파일 이름, 작성자 아이디(`owner`), 브라우저 정보(User-Agent)가 들어갑니다. 로그를 공유할 때 참고하세요.

## 브라우저 지원

압축 해제에 `DecompressionStream`을 사용합니다.

| 브라우저 | 최소 버전 |
|---|---|
| Chrome / Edge | 80 |
| Safari (macOS·iOS) | 16.4 |
| Firefox | 113 |
| 삼성 인터넷 | 13 |

지원하지 않는 브라우저에서는 시작할 때 로그에 오류로 표시됩니다. 25MB 파일 기준 메모리를 대략 파일 크기의 3배(원본 + 해제본 + 이미지) 사용합니다.

## 문제 제보

파일이 안 열리거나 화면이 이상하면:
1. 왼쪽 아래 도구 막대(첫 화면에서는 맨 아래 안내 문구)의 **Log 보기** → **로그 저장**
2. 저장된 `파일명_log.txt`와 증상(몇 장에서 무엇이 이상한지)을 GitHub 이슈로 보내 주세요.
3. 작품 파일 자체는 저작권이 작가에게 있으니, 작가 본인이거나 허락받은 경우에만 공유해 주세요.

## 개발·로컬 실행

빌드 과정이 없습니다. `player/index.html`을 브라우저로 바로 열면 됩니다(`file://`에서도 동작).
로컬 서버로 확인하려면:

```bash
python3 -m http.server 8000 --directory player
```

명령줄 추출기(Python 3.8+, 표준 라이브러리만 사용):

```bash
python3 tools/ucn_extract.py 작품.ucn out/
```

`out/assets/`(이미지), `out/script.xml`, `out/story.json`(장별 타임라인)이 만들어집니다. `.ucn`과 `out/`은 `.gitignore`에 들어 있습니다.

## 배포
